# Промпты для вейб-кодинга TransLogix

## Промпт 1. Проработка идеи и сценариев

```text
Мне нужно создать прототип сервиса TransLogix для лабораторной работы по ПРИС.
Описание: интеллектуальная логистическая система, оптимизирующая маршруты доставки и управление складскими запасами с помощью искусственного интеллекта.
Сформируй пользовательские сценарии, структуру данных, основные сущности и первичную архитектуру MVP.
```

## Промпт 2. Генерация backend

```text
Создай FastAPI backend для прототипа TransLogix.
Нужны endpoint'ы: health, warehouses, deliveries, dashboard, optimize-route, inventory forecast, alerts, history, metrics.
Данные можно хранить in-memory.
Маршрутизация должна учитывать приоритет доставки и расстояние.
Прогноз запасов должен учитывать склад, период и сценарий спроса.
```

## Промпт 3. Генерация frontend

```text
Создай frontend без сборщика: index.html, style.css, app.js.
Интерфейс должен выглядеть как dashboard: карточки статистики, выбор склада, построение маршрута, визуальная лента маршрута, таблица прогноза запасов, оповещения, история операций и метрики.
Все действия должны обращаться к FastAPI backend через fetch.
```

## Промпт 4. Тестирование

```text
Создай pytest-тесты для FastAPI приложения.
Проверь health, dashboard, optimize-route, inventory forecast, alerts и ошибку при неизвестном складе.
```

## Промпт 5. Docker

```text
Добавь Dockerfile и docker-compose.yml для запуска FastAPI приложения на порту 8000.
```
