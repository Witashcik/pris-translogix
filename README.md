# TransLogix · Лабораторная работа №1

Улучшенный MVP-прототип для задания «Разработка и анализ сервисов с помощью вейб-кодинга».

## Что реализовано

- FastAPI backend.
- HTML/CSS/JS frontend без сложной сборки.
- Dashboard с ключевыми показателями.
- Выбор склада и стратегии маршрутизации.
- Визуальная лента маршрута на фронтенде.
- Прогноз складских запасов с выбором периода и сценария спроса.
- Таблица складских рисков и рекомендаций.
- Оповещения по потенциальным проблемам запасов.
- История последних операций.
- Метрики производительности: CPU, память, количество объектов.
- Swagger-документация API.
- Dockerfile и docker-compose.yml.
- Автотесты основных endpoint'ов.
- Текст отчёта в `docs/lab1_report.md`.

## Запуск локально

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\activate
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Запуск:

```bash
uvicorn app.main:app --reload
```

Открыть:

```text
http://127.0.0.1:8000
```

Swagger:

```text
http://127.0.0.1:8000/docs
```

## Запуск через Docker

```bash
docker compose up --build
```

После запуска открыть:

```text
http://127.0.0.1:8000
```

## Проверка тестами

```bash
pytest
```

## Что показывать на видео

1. Главную страницу и статус backend `ok`.
2. Dashboard: склады, точки доставки, срочные доставки, загрузка складов.
3. Блок оптимизации маршрута: выбрать склад, стратегию и нажать «Построить маршрут».
4. Показать карточки расстояния, времени, стоимости топлива и оценки маршрута.
5. Показать визуальную ленту маршрута.
6. Блок прогноза запасов: выбрать склад, период и сценарий спроса.
7. Показать таблицу товаров, статусы `ok`, `warning`, `risk` и рекомендации.
8. Блок данных: вывести склады и точки доставки.
9. Блок оповещений и истории операций.
10. Блок метрик.
11. Swagger-документацию `/docs`.

## Если используется Python 3.14

Если установка падает на `pydantic-core`, лучше использовать Python 3.12/3.13. Это самый стабильный вариант для учебного проекта.

```powershell
rmdir /s /q .venv
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```
