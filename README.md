# TransLogix · Лабораторная работа №1

Улучшенный MVP-прототип для задания «Разработка и анализ сервисов с помощью вейб-кодинга».

## Что реализовано

- FastAPI backend.
- HTML/CSS/JS frontend без сложной сборки.
- Dashboard с ключевыми показателями.
- Выбор склада и стратегии маршрутизации.
- Визуальная лента маршрута на фронтенде.
- Прогноз складских запасов с выбором периода и сценария спроса.
- Таблица складских рисков и рекомендаций.
- Оповещения по потенциальным проблемам запасов.
- История последних операций.
- Метрики производительности: CPU, память, количество объектов.
- Swagger-документация API.
- Dockerfile и docker-compose.yml.
- Автотесты основных endpoint'ов.
- Текст отчёта в `docs/lab1_report.md`.

## Структура

```text

```
